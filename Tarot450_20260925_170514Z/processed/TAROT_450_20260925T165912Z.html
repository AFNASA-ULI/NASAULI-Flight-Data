Real-time clock (RTC) not set. RTC_UTC reads 2026-04-01 14:44:00, but the flight is on 2026-09-25.

HB_Armed mixes heartbeats from several MAVLink components. The raw HB_Armed column flips 420 times. The cleaned armed column only uses autopilot heartbeats (base_mode bit 0 set) and changes 2 times. The logger should filter heartbeats to the autopilot's sysid/compid.
